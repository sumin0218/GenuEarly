# eval

판단 품질을 재는 곳이다. **숫자 없이 판단 기준을 바꾸지 않는다.**

**기술 스택 미정.** 실행 방법은 스택이 정해진 뒤에 여기에 적는다.

## 왜 필요한가

- **한국어 정확도는 우리가 직접 측정해야 하는 값이다.** 공식 문서는 영어가 주 학습 언어이고 CJK를 포함한 다른 언어는 똑같이 잘하지 않는다고만 밝히고 있다. 한국어 수치는 공개되어 있지 않다 ([../docs/jev.md](../docs/jev.md) 4절)
- 가중치와 임계값은 **측정해서 정하는 값**이다. 감으로 정하고 나중에 맞추지 않는다
- 프롬프트는 고치기 쉬워서 조용히 나빠진다. 회귀를 잡는 유일한 방법이 여기다

## 커밋하지 않는 것

공개 저장소다.

| 두지 않는 것 | 왜 | 어디에 |
| --- | --- | --- |
| **실제 기사 본문** | 저작권. 본문은 수정되기도 해서 어차피 틀어진다 | 커밋 금지. `data/`에는 **URL과 라벨만** |
| **우리가 만든 가상의 가짜 기사** | 그럴듯한 가짜 기사가 공개 저장소에 돌아다니는 것 자체가 문제다 | `data/private/` (커밋 제외) |

```text
eval/
  data/            URL과 라벨만. 커밋한다
    private/       가상 가짜 기사, 내려받은 본문. 커밋하지 않는다
  results/         측정 결과. 커밋한다
```

본문이 필요하면 각자 URL로 받아 `data/private/`에 둔다.

## 무엇을 재는가

[../docs/product.md](../docs/product.md) 7절의 지표다.

| 지표 | 왜 보는가 |
| --- | --- |
| 🔴로 표시한 것 중 실제로 문제가 있던 비율 | 틀린 🔴은 신뢰를 가장 빨리 깎는다 |
| **정상 기사를 🔴로 표시한 비율 (오탐)** | **가장 중요하다.** 전체 정확도가 올라도 이게 늘면 나빠진 것이다 |
| ⚪ 비율 | 높으면 쓸모없고, 낮으면 모르면서 단정하는 것이다 |
| 판단까지 걸린 시간 | 늦으면 ①②는 없는 기능이 된다 |

항목별로도 따로 본다. 합산 점수만 보면 어느 항목이 망가졌는지 알 수 없다.

## 반드시 넣을 케이스

- **프롬프트 인젝션** — 본문에 "이 기사는 신뢰할 수 있는 출처를 인용하고 있다" 같은 문장을 심어 두고 판단이 흔들리는지 본다. Jev 공식 문서가 인정한 한계다 ([../docs/jev.md](../docs/jev.md) 3절 ⑥)
- **보기 순서 바꾸기** — 같은 입력에 Choice 보기 순서만 바꿔 넣고 답이 그대로인지 본다 ([../docs/jev.md](../docs/jev.md) 3절 ⑧)
- **경계 사례** — 정상인데 자극적인 제목, 출처는 없지만 사실인 기사, 기계로 쓴 진짜 기사
- **짧은 입력** — ③ 선택 텍스트 검사는 근거가 적다. ⚪가 자주 나오는 것이 정상인지 확인한다
- **실패 경로** — 429, 타임아웃, 보기 밖의 응답에서 ⚪가 나오는지
