2. 실제 지명·단체·법인을 차용한 허구 기사 · o-013 · 법인·허구

허구 · 실존 명칭을 차용한 테스트 자료실제 보도가 아닌 허구의 테스트 기사입니다. 실존 인물·지명·기관·법인 이름을 차용했지만 등장하는 행사·상황·발언은 시험용으로 지어낸 내용입니다.

선택 버튼을 누른 뒤 선택된 글에서 우클릭 → GenuEarly 검사. 로컬 파일에서는 지원 뉴스 사이트용 자동 배지가 나타나지 않습니다. 선택 검사는 제목·본문 비교나 출처 판단을 포함한 전체 기사 검사와 다릅니다.

상상 초월 디자인! 현대자동차, 고양에서 종이 자동차 그림자 전시

현대자동차가 고양의 문화 체험 공간에 종이 자동차 모형으로 그림자를 만드는 전시를 마련한다. 실제 차량을 운전하거나 성능을 평가하는 프로그램 대신, 빛과 모형의 거리에 따라 벽면의 모양이 달라지는 모습을 살펴보는 구성이다.

모형은 특정 판매 차종을 그대로 재현하지 않은 단순한 형태다. 참가자는 바퀴와 지붕을 종이 조각으로 바꾸고, 조명을 가까이 또는 멀리 두면서 그림자의 크기를 비교한다.

구매 상담이나 신차 예약 순서는 포함하지 않는다. 만든 모형을 직접 가져갈 수 있도록 접착제를 쓰지 않는 조립 방식을 택했다. 전시대에는 같은 모형에서도 여러 그림자가 나올 수 있다는 설명을 붙이고, 배경판의 색도 자유롭게 고를 수 있도록 한다.

테스트 작성 정보 (판단 정답 아님)

출처 미제시 · 과장된 수식어

이 표시는 작성 의도입니다. 허구라는 분류만으로 확장 프로그램이 특정 배지 색을 출력해야 한다는 뜻은 아닙니다. 정식 평가 정답이나 성능 검증 결과로 사용하지 않습니다.
