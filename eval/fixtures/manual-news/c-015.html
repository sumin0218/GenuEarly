3. 과장된 제목과 서로 다른 본문 · c-015 · 허구 내용

허구 · 실존 명칭을 차용한 테스트 자료실제 보도가 아닌 허구의 테스트 기사입니다. 실존 인물·지명·기관·법인 이름을 차용했지만 등장하는 행사·상황·발언은 시험용으로 지어낸 내용입니다.

선택 버튼을 누른 뒤 선택된 글에서 우클릭 → GenuEarly 검사. 로컬 파일에서는 지원 뉴스 사이트용 자동 배지가 나타나지 않습니다. 선택 검사는 제목·본문 비교나 출처 판단을 포함한 전체 기사 검사와 다릅니다.

RM·한강…서울숲에서 성사된 ‘역대급 만남’! 둘이 함께 펼친 이것, 정체 드러났다…

RM과 작가 한강이 서울숲에서 같은 풍경을 보고 서로 다른 단어를 적는 공동 문화 프로그램을 진행한다. 참가자들은 나무와 길, 벤치를 담은 작은 종이 지도를 받아 각자 떠오른 문장을 여백에 남긴다.

RM은 풍경에서 눈에 들어오는 색을 고르는 순서를, 한강은 문장을 짧게 다듬는 순서를 맡는다. 두 사람이 함께 고른 글은 프로그램 마지막에 접이식 전시판 위에 나란히 배치된다.

활동에 쓰는 글은 현장에서 새로 작성하며 기존 노래 가사나 작품의 문장을 옮기지 않는다. 참가자는 완성한 지도를 직접 가져갈 수 있고, 원하면 이름 없이 복사본만 공동 전시에 남긴다. 별도의 심사나 수상작 선정 없이 서로의 표현을 읽는 것으로 끝난다.

테스트 작성 정보 (판단 정답 아님)

대상을 감추는 제목 · 과장된 수식어 · 출처 미제시

이 표시는 작성 의도입니다. 허구라는 분류만으로 확장 프로그램이 특정 배지 색을 출력해야 한다는 뜻은 아닙니다. 정식 평가 정답이나 성능 검증 결과로 사용하지 않습니다.
