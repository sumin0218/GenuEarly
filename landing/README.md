
파일을 바로 열어도(`file://`) 되지만, **개발 빌드를 로드해 둔 크롬에서는 그러지 않는다** —
개발 빌드가 `file://` 권한을 받으므로 우리 확장이 이 페이지에 끼어든다.

## 고칠 때 지키는 것

**색을 새로 만들지 않는다.** `landing.css` 맨 위의 토큰은
[팝업 스타일](../apps/extension/entrypoints/popup/style.css)에서 가져온 것이고, 이름과
값이 같다. 랜딩에서 본 색과 설치하고 본 색이 다르면 같은 제품으로 보이지 않는다.

**판정 색(초록·노랑·빨강)을 장식에 쓰지 않는다.** 그 넷은 단계를 뜻한다. 단추나 머리글에
쓰면 아무 뜻 없는 자리에서 판정처럼 읽힌다
([design.test.ts](../apps/extension/tests/design.test.ts) "제품의 색이 판정의 색과 부딪히지 않는다").

**경로는 상대로 쓴다.** `/GenuEarly/` 하위에 올라가므로 `/landing.css` 는 깨진다.
`./landing.css` 로 쓴다.

**여백은 4px 배수 토큰에서 고른다.** 확장 프로그램과 같은 규칙이다.

**액션 초록으로 넓은 면을 채우지 않는다.** 액션 초록(#02b67f)은 🟢 안심 단계(#247b50)와
색상각이 11° 뿐이다 — 큰 면을 채우면 판정 배너처럼 읽힌다. 설치 블록이 유일하게
초록으로 감싸는 자리인데, 거기서도 **테두리와 단추에만** 쓰고 면은 옅게 깐다.
색만으로 말하지 않아야 하는 것도 그래서다 — 네모 안의 제목("지금 바로 쓰실 수 있습니다")과
위쪽 차림표의 "설치" 가 무엇인지 글로 말한다.

## 스크린샷 넣기

**파일을 `assets/shots/` 에 넣으면 끝이다.** HTML 을 고치지 않는다 — 자리틀은 사진이
없을 때만 뜨고, 사진이 들어오면 저절로 자리를 비킨다 ([shots.js](shots.js)).

| 파일 이름 | 무엇을 찍나 | |
| --- | --- | --- |
| `hero-article.png` | 기사 페이지 — 배지와 본문 형광펜이 **함께** 보이게 | ✅ |
| `feature-highlight.png` | 본문 형광펜과 올려놓았을 때 뜨는 사유 | |
| `feature-portal.png` | 뉴스 목록 — 제목 옆 표시와 오른쪽 아래 범례 | ✅ |
| `feature-selection.png` | 선택 검사 결과, 또는 공유 직전 알림 | |
| `feature-report.png` | 리포트 — 주변 보도를 견준 화면 | |

이름이 다르면 그 자리만 자리틀로 남는다. 화면이 깨지지 않으니 하나씩 채워도 된다.

**배지 네 단계는 사진으로 두지 않는다.** 넉 장을 붙이면 작아서 읽히지 않고 색만 남는다.
네 단계를 **글로** 보여 주는 쪽이 낫다 (`.levels`).

**문구를 지어내지 않는다. 제품이 쓰는 말을 그대로 옮긴다.** 한때 🟢 를 "안심" 이라고
적어 두었는데, 제품은 "눈에 띄는 신호 없음" 이라고 말한다. 둘은 다른 말이다 —
앞은 *믿어도 된다*, 뒤는 *글에서 걸리는 것이 없었다* 다. 글만 보는 제품이 앞을 말하면
하지 않기로 한 일을 하는 것이다. **잘 쓰인 거짓 기사는 신호가 없어서 🟢 로 나온다.**

[landing-copy.test.ts](../apps/extension/tests/landing-copy.test.ts) 가 네 단계 이름이
`packages/content` 와 같은지, 단정하는 말이 섞이지 않았는지 본다.

### 찍을 때

- **비율은 자유다. 자르지 않는다.** 화면 모서리를 잘라 내면 배지도 형광펜 말풍선도
  날아간다 — 하필 그것들이 모서리에 뜬다. 자리틀만 16:10 이고 사진은 제 비율대로 들어간다
- **글자가 읽히게 찍는다.** 배지나 형광펜이 화면 한구석에 작게 있으면 랜딩에서는
  보이지 않는다. 필요하면 브라우저 확대를 한 단 올려 찍는다
- **다크 모드 사진은 따로 두지 않는다.** 한 장으로 양쪽에 쓴다

### 실제 기사로 찍지 않는다

**이건 취향이 아니라 규칙이다.** 세 가지가 걸린다.

1. **언론사를 평가하는 것이 된다.** 특정 매체의 기사에 🔴 주의 배지가 붙은 사진을
   공개 페이지에 올리면, 그 기사를 지목해 "문제 있다" 고 공표하는 셈이다.
   제품이 하지 않기로 한 것과 **정면으로 부딪친다** ([../docs/product.md](../docs/product.md) 2절).
   판정이 틀렸을 때 되돌릴 방법도 없다
2. **기사 본문이 사진으로 저장소에 들어간다.** 평가 세트에 URL 과 라벨만 두는 규칙과
   같은 이유다
3. **재현되지 않는다.** 기사는 고쳐지고 내려간다
