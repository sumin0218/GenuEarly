무엇을 보내고
무엇이 남는지

GenuEarly 는 계정을 만들지 않습니다. 광고도, 분석 도구도, 추적도 없습니다. 기사를 판단하는 데 필요한 것만 보내고, 남는 것은 사용자의 브라우저 안에만 있습니다.

마지막 고침 2026년 11월 4일 · 적용 판 v1.1.0

1. 밖으로 나가는 것

기사 글이 나갑니다.

판단은 사용자의 컴퓨터가 아니라 AI 모델이 합니다. 그래서 판단할 글이 밖으로 나갑니다. 이것을 감추지 않고 적습니다.

무엇이

  • 지원하는 뉴스 사이트에서 기사를 열었을 때 — 그 기사의 제목과 본문
  • 뉴스 목록 페이지에서 — 목록에 보이는 기사 제목들
  • 글을 드래그해 검사를 눌렀을 때 — 드래그한 글
  • 리포트를 만들 때 — 위의 기사 글과, 주변 보도를 찾기 위한 검색어

어디로

  • GenuEarly 중계 서버 (genuearly-proxy.workers.dev, Cloudflare Workers)
  • 중계 서버가 ChatKHU API 게이트웨이로 넘깁니다. 거기서 Jev 등 모델이 판단합니다

왜 중계를 거치나

  • API 키를 확장 프로그램에 넣지 않기 위해서입니다. 확장 프로그램 안의 값은 누구나 꺼내 볼 수 있습니다. 키는 중계 서버의 환경변수에만 둡니다

기사를 열지 않으면 아무것도 나가지 않습니다. 지원하지 않는 사이트에서는 확장 프로그램이 동작하지 않습니다. 설치만 해 두고 뉴스를 읽지 않으면 요청이 한 건도 생기지 않습니다.

2. 서버에 남는 것

기사 글은 저장하지 않습니다.

중계 서버에는 데이터베이스가 붙어 있지 않습니다. 기사 글은 받아서 넘기고 버립니다.

남기지 않는 것

  • 기사 제목·본문·드래그한 글 — 한 글자도 저장하지 않습니다
  • 사용자가 어떤 기사를 열었는지 — 기록하지 않습니다
  • 판단 결과 — 서버에 쌓지 않습니다

잠깐 쓰는 것

  • IP 주소 — 분당 요청 수를 세어 폭주를 막는 데만 씁니다. 메모리에만 있고 저장되지 않으며, 기사 내용과 묶이지 않습니다
  • 동작 기록(로그) — "요청이 몇 건이었고 성공했는지" 같은 숫자만 남습니다. 기사 글도 IP 도 로그에 쓰지 않습니다

우리 밖

  • 중계는 Cloudflare 위에서 돕니다. 통신 과정에서 Cloudflare 가 접속 정보를 처리할 수 있습니다
  • 판단은 ChatKHU API 게이트웨이가 합니다. 보낸 글의 처리는 그쪽 정책을 따릅니다

3. 브라우저에 남는 것

셋뿐이고
전부 지울 수 있습니다.

모두 사용자의 브라우저 안에만 있습니다. 서버로 올라가지 않고, 다른 기기와 동기화되지 않습니다.

판단 캐시

주소의 해시와 항목별 점수만. 기사 글도, 주소 원문도, 읽은 시각도 넣지 않습니다

6시간 뒤 사라짐

보고 있는 리포트

기사 인용이 들어 있어 디스크에 두지 않습니다. 브라우저를 닫으면 사라집니다

세션에만

리포트 보관함

제목과 주소. 사용자가 리포트를 만들었을 때만 한 줄 쌓입니다. 20건까지

30일 뒤 사라짐

지우는 법 — 보관함은 확장 프로그램 안에서 전체 삭제할 수 있습니다. 캐시를 포함해 전부 지우려면 크롬에서 확장 프로그램을 삭제하면 됩니다. 삭제하면 위 셋이 함께 사라집니다.

4. 받는 권한

둘뿐입니다.

모든 사이트를 읽는 권한(<all_urls>)을 받지 않습니다. 주소를 하나하나 적어 둔 뉴스 사이트에서만 동작합니다.

storage

  • 위 3절의 셋을 브라우저에 두기 위해서입니다. 다른 용도로 쓰지 않습니다

contextMenus

  • 드래그한 글을 오른쪽 클릭으로 검사하는 메뉴를 넣기 위해서입니다

사이트 접근

  • 네이버 뉴스, 다음 뉴스, 인사이트, 위키트리의 기사와 목록 주소만 적어 두었습니다
  • 네이버의 댓글 페이지는 일부러 빼 두었습니다
  • 적어 둔 주소 밖에서는 확장 프로그램이 뜨지 않습니다

5. 하지 않는 것

파는 일도
쫓는 일도 없습니다.

없는 것

  • 계정·로그인·회원가입
  • 광고, 광고 식별자
  • 분석 도구(Google Analytics 등), 쿠키 심기
  • 사이트를 넘나드는 추적
  • 데이터 판매·대여·제3자 제공(위 2절의 처리 위탁 외)
  • 원격 코드 실행 — 확장 프로그램은 스토어에 올린 코드만 돌립니다

아동

  • 만 14세 미만을 대상으로 만들지 않았고, 나이를 묻거나 수집하지 않습니다
