# 증빙 자료

서식4의 증빙 원칙은 이렇다.

> 전체 대화기록을 무조건 제출하기보다 **핵심 프롬프트 · 버전 변화 · 검증 결과**를 선별해 첨부하고,
> **개인정보 · API 키 · 비공개 정보는 반드시 제거**합니다.

그 "검증 결과"에 해당하는 파일을 여기 둔다. 본문 기록은 단계별 파일에 있고, 여기는 그것을 뒷받침하는 자료다.

## 규칙

- 파일 이름은 `YYYY-MM-DD-무엇.확장자`
- **개인정보·API 키가 찍힌 캡처를 넣지 않는다.** 넣기 전에 화면을 다시 본다
- 실제 기사 본문이 담긴 자료를 넣지 않는다
- 어느 기록을 뒷받침하는지 아래 표에 적는다

## 목록
