- 서명본은 `docs/submission/signed/`에 두고 커밋에서 제외한다 ([.gitignore](../../.gitignore))

## 서식3 프로젝트 소개서

분량 제한이 있다. **채워야 할 칸이 곧 심사 항목**이다.

| 항목 | 분량 | 요강이 요구하는 내용 | 끌어올 곳 |
| --- | --- | --- | --- |
| 작품 요약 소개 | 1,000자 | | [../../README.md](../../README.md) |
| 1. 문제 인식과 주제 적합성 | 1,000자 | 해결하려는 문제, 주제 선정 배경·필요성·목적·기대효과 | [../product.md](../product.md) 1절 |
| 2. 핵심 아이디어와 사용자 경험 | 제한 없음 | 주요 기능, 화면·체험 순서. **이미지·도표 삽입** | [../product.md](../product.md) 3절 |
| 3. 창의성·차별성 | **500자** | 기존 사례와 비교한 독창적 요소, **단순 생성과 구별되는 사람의 기획·편집** | [../product.md](../product.md) 2절, [../jev.md](../jev.md) |
| 4. 실용성·완성도·확장성 | 1,000자 | 현재 구현 수준, 작동 범위, 한계, 향후 고도화, 예상 효과 | [../../eval/results/](../../eval/results/) |

기본 정보도 적는다: 부문(AI 문제해결 솔루션), 팀명, 팀장, 아이디어명, **작품 형태**(우리는 "기타 — 크롬 확장 프로그램"에 해당), 작품 제출 파일 목록.

> **3번이 500자뿐이다.** "진위를 단정하지 않는다", "모르면 모른다고 한다(⚪)", "공유를 막지 않는다" 같은
> 우리가 **일부러 하지 않기로 한 선택**이 여기 들어가야 할 내용이다. 그게 사람의 기획이다.
