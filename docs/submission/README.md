## 커밋하지 않는 것

**서명이 들어간 서류를 커밋하지 않는다.** 공개 저장소이고, 서명란에는 이름과 학번이 들어간다.

- 서명본은 `docs/submission/signed/`에 두고 커밋에서 제외한다 ([.gitignore](../../.gitignore)).
- 저장소에는 **서명 없는 작성본과 내용**만 둔다.
- 서류를 공유할 때는 저장소가 아니라 팀이 쓰는 비공개 채널로 보낸다.
